# Manual test cases — US-003 Walkthrough for first-time users

Written by the `@tester` verification agent (`test` skill) for criteria that are
React UI behaviour. The project has no component-testing library, and adding one
needs the team's approval (see *Awaiting approval* in
`docs/verification-report.md`). The logic behind these criteria
(`src/src/services/onboarding.ts`) is also covered by automated tests in
`src/src/services/onboarding.test.ts`.

**Environment:** `npm run dev:client` (Vite, `http://127.0.0.1:5173`), Chromium
browser pane, 800×600 viewport, branch `verification-agents`.
**Executed:** 2026-11-20. **Result:** 4/4 PASS.

"Seen flag" means `localStorage["hokie-scheduler:walkthrough-seen"]`, read in
DevTools.

## MT-003-1 — Progress dots jump to a step

@ac US-003.AC3

**Precondition:** seen flag cleared, app reloaded, walkthrough open on step 1.

| # | Step | Expected |
|---|------|----------|
| 1 | Click the 4th progress dot | Shows "Step 4 of 5", title "Manage your calendar"; 4th dot has `aria-current="step"` and is the only one that does |
| 2 | Click the 5th progress dot | Shows "Step 5 of 5", title "Compare schedules"; only the 5th dot has `aria-current="step"` |

**Observed:** as expected for both steps. **PASS**

## MT-003-3 — Every close method closes and remembers

@ac US-003.AC5

| # | Close method | Expected |
|---|--------------|----------|
| 1 | Close (X) button | Closes; seen flag `"true"` |
| 2 | Escape key | Closes; seen flag `"true"` |
| 3 | Click on the backdrop outside the dialog | Closes; seen flag `"true"` |
| 4 | "Skip" (step 1) | Closes; seen flag `"true"` |

**Observed:** all five methods closed the walkthrough and set the flag. **PASS**
